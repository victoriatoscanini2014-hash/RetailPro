# RetailPro 📊

## Proyecto de Análisis de Datos

RetailPro es un proyecto académico de análisis de datos orientado al estudio de ventas y comportamiento comercial.

El objetivo es transformar datos comerciales en información útil para la toma de decisiones mediante un flujo de trabajo que integra SQL, procesos ETL, modelado de datos, DAX y visualización en Power BI.

---

## 🛠️ Herramientas utilizadas

- PostgreSQL
- Power Query
- Power BI
- DAX
- Excel
- GitHub
- Inteligencia Artificial como apoyo para documentación, revisión y validación

---

## 🔄 Flujo del proyecto

El proyecto se desarrolló siguiendo un proceso progresivo de análisis:

**SQL → Consultas de negocio → JOINs → ETL → Modelo de datos → DAX → Power BI**

### SQL

Se construyeron consultas para explorar y analizar la información comercial de RetailPro.

Entre los análisis realizados se encuentran:

- Facturación mensual.
- Cantidad de pedidos.
- Ticket promedio.
- Ranking de productos.
- Identificación de clientes recurrentes.
- Comparación de facturación respecto al promedio.
- Integración de ventas, clientes, productos y categorías mediante JOINs.

### ETL

Los datos fueron transformados mediante Power Query para realizar tareas de limpieza, preparación y estructuración antes de incorporarlos al modelo analítico.

### Modelado y DAX

En Power BI se construyó el modelo de datos y se desarrollaron medidas DAX para obtener indicadores relevantes para el análisis comercial.

### Visualización

Se desarrollaron visualizaciones orientadas a facilitar la interpretación de los principales indicadores y resultados del proyecto.

## 📂 Archivos principales

- `m3_estructura_datos.sql` — estructura de datos del proyecto.
- `m4_consultas_negocio.sql` — consultas SQL orientadas al análisis de negocio.
- `m5_consultas_joins.sql` — integración de tablas mediante JOINs.
- `Pipeline_ETL_Dataset.xlsx` — dataset utilizado en el proceso ETL.
- `Pipeline_ETL_Toscanini_Victoria.pbix` — desarrollo del pipeline ETL en Power BI.
- `Toscanini_Victoria_Checkpoint2.pbix` — modelo de datos, medidas DAX y visualizaciones.
- `m7_power_bi/` — documentación y recursos correspondientes al desarrollo en Power BI.

## ▶️ Ejecución de los scripts SQL

1. Clonar o descargar este repositorio.
2. Abrir el script SQL correspondiente.
3. Conectarse a la base de datos utilizada en el proyecto.
4. Verificar que las tablas necesarias estén disponibles.
5. Ejecutar las consultas en el orden correspondiente.
6. Validar los resultados obtenidos antes de utilizarlos en el análisis.

## 🤖 Uso de Inteligencia Artificial

Durante el desarrollo de RetailPro se utilizó Inteligencia Artificial como herramienta de apoyo para revisar código, generar documentación y mejorar la interpretación de resultados.

Las respuestas generadas por IA fueron sometidas a validación técnica y los resultados numéricos utilizados en el proyecto se contrastaron con las fuentes de datos correspondientes.

La IA fue utilizada como copiloto del proceso, manteniendo el criterio y la validación final bajo responsabilidad del analista.

Construir un flujo de análisis reproducible que permita transformar datos de ventas en información comercial clara, trazable y útil para la toma de decisiones.
